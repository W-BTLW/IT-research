# 🚨 CVE-2026-111497 (Node2Shell) 1분 브리핑

안녕하세요, 최근 발견되어 활발히 악용 중인 심각한 보안 취약점 **CVE-2026-111497**, 일명 **'Node2Shell'**에 대해 브리핑하겠습니다.

## 1. 취약점 개요 (이게 무엇인가?)
이 취약점은 Node.js 등 여러 웹 환경에서 광범위하게 쓰이는 **Brotli 압축 해제 라이브러리**에서 발생한 메모리 결함(버퍼 오버플로우 및 Out-of-bounds write)입니다. 
공격자가 조작된 Brotli 압축 데이터를 서버에 전송하면, 이를 해제하는 과정에서 서버 메모리가 손상되거나 통제권이 넘어가 **원격 코드 실행(RCE)**이 발생할 수 있는 치명적인 고위험군(High Severity) 취약점입니다.

## 2. 발견 및 현황 (어떻게 알려졌는가?)
해당 결함은 2026년 10월 말, Brotli 디코더가 압축 데이터를 처리할 때 잘못된 블록 타입을 제대로 걸러내지 못한다는 사실이 보안 연구원들에 의해 밝혀지며 공개되었습니다. 
가장 큰 문제는 이 취약점이 공개 직후부터 **실제 사이버 공격에 악용(Active Exploitation)**되고 있다는 점입니다. 이에 미국 사이버보안인프라보안국(CISA)은 2026년 10월 27일, 해당 건을 '알려진 악용 취약점(KEV)' 목록에 긴급 추가하고 주의를 당부했습니다.

## 3. 해결 방안 (어떻게 대응해야 하는가?)
가장 확실한 대응책은 영향을 받는 환경을 식별하고 **신속하게 업데이트**하는 것입니다.

* **Node.js 패치 적용**: 취약점이 해결된 최신 버전(22.23.4, 24.22.1, 26.12.1 등)으로 즉시 업그레이드해야 합니다. 지원이 종료된 20.x, 23.x, 25.x 등의 버전은 패치가 제공되지 않으므로 최신 라인으로의 마이그레이션이 필수적입니다.
* **컨테이너 이미지 재빌드**: 단순히 런타임 버전만 올리는 것이 아니라, 패치된 Node.js를 기반으로 Docker 등의 컨테이너 이미지를 새로 빌드하고 배포해야 완전히 조치됩니다.
* **임시 차단 조치**: 당장 서버 업데이트가 어렵다면 Palo Alto 등 네트워크 보안 장비(방화벽) 설정에서 임시로 'Brotli 인코딩 검사' 기능을 비활성화하여 악의적인 트래픽을 차단할 수 있습니다.

시스템 담당자분들은 서비스의 Brotli 사용 여부를 점검하시고, 가급적 오늘 중으로 패치 적용을 완료해 주시기 바랍니다. 이상으로 브리핑을 마칩니다.
