# 네트워크 교환 방식 비교: 회선교환 vs 패킷교환

## 개요
네트워크에서 데이터를 전송하는 주요 교환 방식은 **회선교환(Circuit Switching)**과 **패킷교환(Packet Switching)** 두 가지입니다. 전통 전화망은 회선교환, 현대 인터넷은 패킷교환을 사용합니다.

## 회선교환 방식 (Circuit Switching)

### 특징
전화 통화처럼 통신 시작 전 **전용 회선**을 예약해 독점 사용합니다.

### 장단점
| 구분 | 내용 |
|------|------|
| **장점** | - **지연시간 일정**: 실시간 통신에 최적<br>- **품질 보장**: 대역폭 독점 확보<br>- 순서 보장 |
| **단점** | - **자원 낭비**: 사용하지 않을 때도 회선 점유<br>- **설정 지연**: 연결까지 數초 소요<br>- 유휴 회선 효율 저하 |

## 패킷교환 방식 (Packet Switching)

### 특징
데이터를 **패킷 단위**로 쪼개 각각 독립 경로로 전송합니다. 인터넷 표준 방식입니다.

### 장단점
| 구분 | 내용 |
|------|------|
| **장점** | - **회선 효율**: 여러 통신 공유<br>- **장애 복구**: 우회 경로 자동 선택<br>- **유연성**: 데이터량에 따른 동적 할당 |
| **단점** | - **가변 지연**: 트래픽에 따라 지연 변동<br>- **순서 보장 안됨**: 재조립 필요<br>- 헤더 오버헤드 발생 |

## 비교표

| 비교항목 | 회선교환 | 패킷교환 |
|----------|----------|----------|
| **대표사용처** | 전화망(PSTN) | 인터넷(IP) |
| **자원할당** | 전용회선 예약 | 공유 사용 |
| **지연특성** | **일정** (예측가능) | **가변** (트래픽의존) |
| **회선효율** | 낮음 | **높음** |
| **실시간성** | **우수** | 보통 |
| **구현복잡도** | 단순 | 복잡 |

## 결론 및 실제 적용 예시
**실시간 음성/영상** → 회선교환  
📞 전화통화
<br/>
└─ 끊임없는 음성 스트림, 중간 끊김 없음

**데이터/인터넷** → 패킷교환  
🌐 웹서핑/영상스트리밍
<br/>
└─ 버퍼링 발생하지만 효율적 자원 사용
